# Pitacco

Código completo da versão 0.11 preservado em `source/*.b64`: partes ordenadas de um ZIP codificado em Base64. O workflow Windows decodifica e verifica SHA-256 antes de compilar. O arquivo extraído contém React, SQL, Rust/Tauri, SQLite, Android, testes e documentação.

Este é um checkpoint de desenvolvimento. Checkout público ainda não possui telas completas; integrações de marketplaces e pagamentos online não estão homologadas. O instalador gerado destina-se a testes e não é assinado com Authenticode.

Em Actions → Pitacco Windows, baixe o artefato Pitacco-Windows-x64 após conclusão com sucesso. O primeiro uso solicita URL e chave pública do Supabase; não use service_role.
